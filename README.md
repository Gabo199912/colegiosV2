# 🎓 Sistema de Gestión Académica
> **"La educación transforma vidas; la tecnología transforma la forma de educar."**

Una plataforma desarrollada para facilitar la administración de instituciones educativas, permitiendo gestionar estudiantes, docentes, cursos, calificaciones y pagos de forma rápida, segura y organizada.

## 🎯 Objetivo

Digitalizar los procesos administrativos de un centro educativo, reduciendo el uso de papel, mejorando el control de la información y facilitando el trabajo de docentes y administradores.



## ✨ Características

- 👨‍🎓 Administración de estudiantes.
- 👨‍🏫 Gestión de docentes.
- 📚 Control de grados, secciones y especialidades.
- 📝 Registro de calificaciones.
- 💰 Control de pagos mensuales.
- 🔐 Sistema de roles y permisos.
- 📊 Reportes y consultas.

## 🛠 Tecnologías

- Java
- Spring Boot
- Spring Security
- JPA / Hibernate
- MySQL
- Maven
